A tiny program that writes one line: the elevator pitch a city pigeon gives
to investors for its startup. The pigeon has been A/B-testing humans for a
century, and now it is selling restaurants the results.

## Run it

```sh
python3 main.py
```

It writes the pitch to `/output/entry.txt` (one line, 187 characters).
Standard library only; the output is identical on every run.
